# ⚠️ 注意道路マップ

ドライバー同士で「狭い道」「通りにくい道」をリアルタイムに共有できるスマホ向け地図アプリです。  
URLを送るだけで仲間と地図データが自動同期されます。

---

## 画面イメージ

| 機能 | 説明 |
|------|------|
| 🔴 道を描く | 地図をタップして注意道路を赤線でマーキング |
| 🗑 削除 | タップした線を1本ずつ削除 |
| ↩ 元に戻す | 直前に追加した線を取り消し |
| 🎯 現在地 | 今いる場所に地図を移動 |

---

## 使い方

### 道を描く
1. 「🔴 道を描く」ボタンをタップ
2. 地図上をタップして点を追加していく
3. 画面右下の **✓ ボタン**を押して確定
4. 赤い線が地図に追加され、仲間の画面にも即座に反映される

### 線を削除する
1. 「🗑 削除」ボタンをタップ
2. 消したい赤線をタップ → 削除される

---

## リアルタイム同期について

- Firebase Realtime Database を使って全員の地図データを自動同期
- URLを開くだけで最新データが表示される
- ステータスバーの●の色で接続状態がわかる
  - 🟢 緑 … 接続・同期済み
  - 🟡 黄 … 同期中
  - 🔴 赤 … オフライン（再接続待ち）

---

## 動作環境

- スマートフォンのブラウザ（iOS Safari / Android Chrome）
- PCブラウザでも使用可能

---

## 使用技術

| 技術 | 用途 |
|------|------|
| [Leaflet.js](https://leafletjs.com/) | 地図表示・描画 |
| [OpenStreetMap](https://www.openstreetmap.org/) | 地図タイル |
| [Firebase Realtime Database](https://firebase.google.com/) | リアルタイムデータ同期 |

---

## 注意事項

- 地図データはFirebaseに保存されます
- URLを知っている人であれば誰でも閲覧・編集できます
- 個人情報は保存されません
