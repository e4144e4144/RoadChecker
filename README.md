# ⚠️ 注意道路マップ

ドライバー向けのリアルタイム道路情報共有ツールです。
クレームが発生した道や通行に注意が必要な道を地図上に記録し、そのエリアを担当するドライバーへの注意喚起として活用できます。

---

## マーキングの目的について

このマップのマーキングは、**注意喚起**を目的としています。

一目でわかる私有地・私道・明らかに狭い道路などは登録不要です。
**「ヒヤリとした」「見落としそうだった」「細心の注意が必要だと感じた」**、そういった瞬間に記録してください。

---

## 機能

| ボタン | 用途 |
|--------|------|
| 🔴 クレーム | クレームが発生した道を記録 |
| 🔵 注意道路 | 通行注意が必要な道を記録（種別選択あり） |
| 🗑 削除 | 線を1本ずつ削除（確認あり） |
| ↩ 元に戻す | 直前の操作を取り消し（確認あり） |
| 🎯 現在地 | 現在地に地図を移動 |

## 使い方

**道を描く**
ボタンを押す → 地図をタップして点を追加 → ✓ボタンで確定

**🔵 注意道路は確定後に種別をプルダウンで選択（複数選択可）**

| 種別 | 内容 |
|------|------|
| 私道 | 一般車両の通行に制限がある道 |
| 狭小路 | 車両のすれ違いが困難な狭い道 |
| 高さ制限 | 車高に制限がある道 |
| 幅員制限 | 車幅に制限がある道 |
| 未舗装道路 | 舗装されていない道 |
| 臨時工事中 | 現在工事中で通行に注意が必要な道 |

**線をタップ**
種別・登録日時を確認できます。

**情報はリアルタイムで同期されます。**
誰かが追加・削除した情報は、同じ地図を開いている全員に即時反映されます。

## 注意事項
- 削除したデータは復元できません
- 地図を開ける人は誰でも編集できます

# ⚠️ Caution Road Map

A real-time road information sharing tool for drivers.
Roads where complaints have occurred or require extra caution are recorded on the map, serving as safety alerts for drivers covering the area.

---

## Purpose of Markings

All markings on this map are intended for **safety awareness only**.

Roads that are obviously restricted — such as private property, private roads, or clearly narrow lanes — do not need to be marked.
**Please record a location when you felt a sudden sense of danger, nearly missed something, or felt that extra caution was absolutely necessary.**

---

## Features

| Button | Purpose |
|--------|---------|
| 🔴 Complaint | Record roads where complaints have occurred |
| 🔵 Caution | Record roads requiring careful driving (with type selection) |
| 🗑 Delete | Remove a line one at a time (with confirmation) |
| ↩ Undo | Revert the last action (with confirmation) |
| 🎯 My Location | Center the map on your current location |

## How to Use

**Draw a road**
Tap a button → tap the map to add points → press ✓ to confirm

**For 🔵 Caution roads, select the type from the dropdown after confirming (multiple selections allowed)**

| Type | Description |
|------|-------------|
| Private road | Road with restricted access for general vehicles |
| Narrow lane | Road too narrow for vehicles to pass each other |
| Height limit | Road with vehicle height restrictions |
| Width limit | Road with vehicle width restrictions |
| Unpaved road | Road without pavement |
| Temporary construction | Road currently under construction requiring caution |

**Tap a line**
View the road type and registration date.

**All information syncs in real time.**
Any addition or deletion is instantly reflected for everyone viewing the same map.

## Notes
- Deleted data cannot be recovered
- Anyone who can access the map can edit it
