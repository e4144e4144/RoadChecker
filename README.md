# 🗺️ 道路判定マップ

> 周辺の道路が**公道か私道か・車で通れるか**をひと目で確認できる無料Webアプリです。

OpenStreetMap（OSM）のオープンデータをリアルタイムに取得し、現在地周辺500mの道路を3段階で色分け表示します。インストール不要、ブラウザで開くだけで使えます。

---

## 📱 デモ・使い方

| 手順 | 操作 |
|------|------|
| 1 | `index.html` をダブルクリックしてブラウザで開く |
| 2 | 「📍 現在地を取得」ボタンを押す |
| 3 | 周辺の道路が色分けして表示される |
| 4 | 道路をタップ・クリックすると詳細情報が表示される |

インターネット接続があれば、追加インストールやサーバー不要で動作します。

---

## 🎨 色の見方

| 色 | 判定 | 該当する道路の例 |
|---|---|---|
| 🔵 **青** | 公道（車で通行可） | 国道・県道・市道・幹線道路・主要道路 |
| 🟡 **黄** | 要注意（狭い道） | 住宅地道路・生活道路・路地・1車線・幅3m未満の道 |
| 🔴 **赤** | 通行不可の可能性あり | 私道・歩行者専用・自転車専用・河川敷・農道・林道・私有地内道路 |

道路をクリックするとポップアップが表示され、道路の名称・種別・判定理由（例：「自転車専用道路」「私有地内道路」「車幅注意（幅2.5m）」）を確認できます。

---

## ⚠️ 重要な注意事項

- 本アプリの判定は **OpenStreetMap のデータに基づく推定** です
- OSMはボランティアによる編集のため、情報が古い・未登録の場合があります
- **100%の精度は保証できません**。実際の通行可否は必ず現地または関係機関にご確認ください
- 私道への無断立ち入りは法的トラブルになる場合があります

## 🚗 判定ロジック

OSMの `highway` タグを基本に、`access` / `service` / `width` / `lanes` / `motor_vehicle` タグで補正しています。

### 🔵 公道（青）
国道・県道・市道レベルの車道が対象です。

| OSMタグ | 道路の種類 |
|---|---|
| `motorway` | 高速道路 |
| `trunk` | 幹線道路 |
| `primary` | 主要道路（国道相当） |
| `secondary` | 二次道路（県道相当） |
| `tertiary` | 三次道路（市道相当） |

### 🟡 要注意（黄）
車が通れる可能性はありますが、狭さや生活道路であることに注意が必要です。

| 条件 | 理由 |
|---|---|
| `residential`（住宅地道路） | 生活道路のため歩行者・子供に注意 |
| `living_street`（生活道路） | 歩行者優先区域 |
| `unclassified`（未分類道路） | 管理状況が不明 |
| `service=alley`（路地） | 狭い可能性あり |
| `width` が 3.0m 未満 | 幅員データが存在し、狭いと判定 |
| `lanes=1` | 1車線で離合困難な可能性 |

### 🔴 通行不可の可能性（赤）
車での通行が難しいか、立入り自体が問題となる可能性がある道路です。

| OSMタグ・条件 | 道路の種類 |
|---|---|
| `footway` / `path` / `pedestrian` | 歩道・歩行者専用道路 |
| `cycleway` | 自転車専用道路 |
| `steps` | 階段 |
| `bridleway` | 河川敷・乗馬道 |
| `track` | 農道・林道 |
| `service=driveway` | 私有地内の進入路 |
| `service=parking_aisle` | 駐車場内通路 |
| `access=private` / `access=no` | 私道・通行禁止 |
| `motor_vehicle=no` / `motorcar=no` | 自動車通行禁止 |

## 🌐 GitHub Pages で公開する方法

GitHub Pages を使うと、スマートフォンを含むどの端末からでもURLでアクセスできるようになります。

1. このリポジトリを自分のGitHubアカウントにフォーク（またはファイルをアップロード）
2. リポジトリの **Settings** → **Pages** を開く
3. **Source** を `Deploy from a branch` に設定、ブランチを `main`、フォルダを `/ (root)` に設定
4. **Save** を押すと数分後にURLが発行される

公開URL例：`https://ユーザー名.github.io/road-checker-app/`

## 🙋 よくある質問

**Q. 現在地が正しく取得できない**  
A. ブラウザの位置情報の許可を確認してください。また、`http://` で開いた場合は位置情報が使えないことがあります。`https://` または `localhost` から開いてください。

**Q. 道路が表示されない**  
A. インターネット接続が必要です。また、Overpass APIのサーバーが混雑していると取得に失敗することがあります。「🔄 再読み込み」を数回お試しください。

**Q. 判定が実際の道路と違う**  
A. OpenStreetMapのデータが古い・未整備の場合があります。OSMアカウントを作成すると誰でも地図を修正・改善できます。

**Q. 商用利用できますか？**  
A. コード自体はMITライセンスで商用利用可能ですが、OSMデータを使用する場合はODbLライセンスの要件（帰属表示・改変データの公開など）を遵守してください。
