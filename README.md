# NarrowAlert — 危険道路チェッカー

地図をクリックするだけで、周辺の危険な道路を自動で検出・色分け表示するWebアプリです。  
**インターネット接続のみで動作。APIキー・サーバー不要。**

---

## 使い方

1. `road-alert.html` をブラウザ（Chrome / Edge / Firefox）で開く
2. 地図上の任意の地点をクリック
3. 周辺の道路が自動解析され、アラートが色分けで表示される

### 住所・地名で検索する場合

右上の検索欄に住所や地名を入力して「検索」ボタンを押すと、その地点に移動して自動解析します。

> 例：`名古屋市中区` / `大阪市西成区` / `東京都世田谷区三宿`

### 解析範囲の変更

左サイドバーの「解析範囲」スライダーで 100m〜600m の範囲を調整できます。  
広くするほど多くの道路を取得しますが、解析に時間がかかります。

## アラートの種類

| 色 | アラート | 検出条件 |
|---|---|---|
| 🔴 赤 | 行き止まり・Uターン不可 | 接続道路が1本だけの端点ノード（幹線道路を除く） |
| 🟠 オレンジ | 狭い道（3.5m以下） | 道幅タグが3.5m未満、または狭い道路種別（サービス道・農道・路地など） |
| 🟣 紫 | 急カーブ・折れ曲がり | 連続する方位角の変化が55°超の地点にマーカー表示 |
| 🔵 青 | 急に狭くなる区間 | 接続ノードで道幅が1.6倍以上縮小する箇所 |

> アラートは優先順位順（赤 → オレンジ → 紫 → 青）に判定されます。  
> 灰色の道路はアラートなしの通常道路です。

### 地図上での確認方法

- **色付きの線** をクリックするとポップアップでアラート詳細を表示
- **左サイドバーのリスト** をクリックすると該当道路にズームイン

## 注意事項

### データ精度について

- OpenStreetMapのデータ品質は地域によって異なります。道幅などの情報が未登録の道路では推定値を使用します。
- 「行き止まり」判定はOSMのノード接続情報に基づくため、実際の通行可否と異なる場合があります。
- 実際に道路に入る前は、必ず現地の状況を目視で確認してください。

### Overpass APIの利用制限

- 無料の公共APIのため、短時間に大量のリクエストを送ると一時的にアクセスが制限されることがあります。
- 解析失敗時は少し時間を置いてから再度クリックしてください。

## 今後の拡張アイデア

- **車両サイズ指定**：2t車・4t車・軽自動車など車幅を入力して通行可否を判定
- **ルート全体チェック**：出発地〜目的地のルート上の危険区間を一括スキャン
- **自社データ統合**：実走ログや独自の危険箇所データとの組み合わせ
- **オフライン対応**：事前に地図データをダウンロードして通信なしで使用
